# Sistema de Gestão de Candidatos

Sistema web completo para **gestão de currículos e candidatos**, com autenticação, painel administrativo e dashboard interativo. Desenvolvido para facilitar processos de análise, aprovação e comparação de candidatos.

---

## 🚀 Funcionalidades

### 🔐 Autenticação
- Login seguro de usuários
- Controle de acesso ao painel administrativo

### 🗂️ Gestão de Candidatos
- Cadastro de candidatos
- Armazenamento em banco de dados
- Classificação e ranqueamento de candidatos
- Comparação entre candidatos

### 🧑‍💼 Painel Administrativo
- Aprovar candidatos
- Rejeitar candidatos
- Visualizar dados detalhados
- Exportar currículo em **PDF**
- Interface intuitiva e organizada

### 📊 Dashboard
- Visualização geral dos candidatos
- Indicadores e estatísticas
- Organização clara das informações

### 🎨 Interface
- Interface moderna e responsiva
- Animações suaves
- Experiência de usuário fluida

---

## 🛠️ Tecnologias Utilizadas
- **Java** (lógica e backend)
- **JavaScript**
- **HTML5**
- **CSS3**
- **Firebase** (banco de dados e autenticação)
- Integração com APIs
- Geração de arquivos PDF
- Dashboard interativo
- Animações no frontend
- Deploy em ambiente web
